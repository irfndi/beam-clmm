## Deployment: Alchemy (research, verified 2026-08-08)

The cloudflare/ subproject is ALREADY migrated to Alchemy v2 by the concurrent
session: `cloudflare/infra/alchemy.run.ts` (alchemy@2.0.0-beta.64 pinned,
Effect 4) declares both workers, D1 `beam-db`, KV `beam-cache`, R2, Vectorize
`beam-memory`, Config.redacted secrets, --adopt + Cloudflare state store.
wrangler.toml files are deleted. Extend this stack — do NOT create a parallel
one.

- **A plain Worker cannot host the scan loop** (timers die with the
  invocation). The engine's `Effect.forever(Effect.sleep(...))` loop needs a
  host: local Bun process / VPS / Docker.
- **Recommended shape (b):** engine stays a CLI/Bun process; per cycle it
  pushes a snapshot (positions/decisions/portfolio) to D1; a new Worker in the
  existing stack serves the `engine/http-status-server.ts` routes
  (`/health /status /positions /decisions /config /propose /approve`) from D1,
  with the same token gates (fail closed on missing tokens). Proposal enqueue →
  engine pickup via the engine's existing HTTP-queue polling.
- DO-alarms variant (a): feasible (alarms have NO documented minimum — 10s
  example; 30s is the CPU limit) but the bun:sqlite → DO-storage port (22
  migrations, sqlite-vec → Vectorize) is multi-week — defer until the adapter
  seam is stable. Containers (c): ephemeral FS → beam.db lost on restart; only
  as interim bridge.
- **Version pins:** alchemy@beta.70 (latest) pulls effect ≥ beta.106 and
  @distilled.cloud/* 1.0.0-rc.2 — bump the whole workspace deliberately
  (root + cloudflare/infra), not during the seam port. Repo pin
  effect 4.0.0-beta.105 is within alchemy's peer range but nested-copy risk
  exists (already present in cloudflare/bun.lock).
- Engine binds its status server to 127.0.0.1 — make the bind host configurable
  for any cloud variant.
- Before first deploy: `bun alchemy cloudflare bootstrap` + `alchemy deploy
  --dry-run`; read the adoption diff (README claims live prod beam-api/beam-db
  — verify; never rename adopted resources).
- Full report: agent://AlchemyDeploy.
